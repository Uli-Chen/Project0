# IELTS Writing Task 2 本地模拟题库

本包是用于 RFC 内容与推荐规则验证的 **38 题 mock**，版本 `mock-20261101-v1`，状态 `mock_not_production`。未导入应用、未部署、未调用模型或联网；没有改动 `/Users/chen/Desktop/雅思` 内任何材料。

28 道普通练习题按唯一主话题各分配 4 题：education、technology、environment、society、work、health、culture。10 道检查点保留题按五种题型各分配 2 题。普通题总体覆盖全部五种题型，但没有要求每话题覆盖五种题型。

| 普通题型 | 数量 | 保留题数量 |
| --- | ---: | ---: |
| agree_disagree | 11 | 2 |
| discuss_both | 7 | 2 |
| adv_disadv | 6 | 2 |

此分布满足暂定容量契约，但并非题型均衡的正式考试测量设计。尤其普通池只有 1 道原因/对策题；正式内容选编可进一步丰富，不能据此声称评测效度已验证。

## 来源和使用边界

32 题为本地英文题干原文摘录，3 题为明确标记的本地改编，3 题为本次补齐配额编写。因此 **复用英文原文 32 题，新写英文 6 题（其中改编 3、原创 3）**。原文摘录只是与本地文件一致，不代表官方真题。

主要材料是 `雅思大作文Top18_图片文字摘录.docx` 的 18 个“原题”段落和 `tmp/1010-public-topics/band_verified.json` 的 19 条英文记录。后者有一组工作搬迁题近重复，按 18 个题目家族计；其中两组又与 Top18 重复。加上 `雅思A类写作8分备考宝典.md` 的两道完整 Task 2，英文候选按家族去重为 36 道。具体选取没有硬凑到 38：选 32 条原文，按话题缺口补 6 条。`雅思作文整理版.docx` 和 `雅思作文.docx` 的内容属于 Task 1，未误收。

改编题：数学与沟通课程、濒危语言资助、电脑智能。前后两题是把本地完整中文题干译为英文；濒危语言条目只有观点方向，明确补了同意/不同意作答指令。原创题：校服要求、成人睡眠减少及影响、历史建筑失修。远程办公题虽然是本地原文摘录，但其来源本来就标为“原创练习题”，未包装成真题。

没有重新核实文件里引用的网站，也没有继承 `band_verified.json` 的 `verified: true` 作为本次权威验证。用户提供的材料可供本地摘取与审阅，但本包不判断公开发行的授权，也不把任何题统一宣称为“官方历年真题”。

## 身份、去重和分类

`id` 是本包内稳定题目身份，`version: 1` 冻结本次记录，`bankOrder` 是 1–38 的唯一确定顺序。发布后修改题干、标签或池应出新版本，并保留历史记录。`exposureKey` 标识题目家族：同命题近似改写必须沿用该值，不能因换字或换版本恢复未接触资格。每题只按 `primaryTopic` 计主话题配额；`secondaryTopics` 不重复增加覆盖数。

逐题阅读后排除了工作搬迁、医疗税收优先、现代相互依赖等重复或近重复来源。普通池与保留池无同家族题，规范化文本无重复。相同话题不自动等于同一题家族；例如野生动物经费是否过多与生态保护是否已太迟，要求判断不同命题。

`problem_solution` 包含“原因＋对策”和“问题＋措施”；`two_part` 用于“原因＋影响”“原因＋正负评价”等非对策的双问题。`adv_disadv` 本批均为 outweigh 权衡题，不能在后续教练里忽略比较要求。

保留池表示内容分配，不证明用户未见题。当地文件已经含有部分题的范文，用户可能看过；检查点资格必须另按应用曝光记录与自报规则判断。题库不包含答案、参考论点、范文、Task 1、阅读或听力题。

## 验证

在任意目录执行：

```sh
python3 /Users/chen/Desktop/opc/data/question-bank/validate_bank.py
```

脚本使用 Python 标准库，读取源文件并更新自身目录的 `validation_report.json`。源文件路径保持原始本地路径；移至其他机器时需一并提供来源材料并显式调整定位，不能把无法复核当作通过。

检查包括：38/28/10 总量；7×4 主话题；5×2 保留题型；普通池五类覆盖；唯一 ID、版本、顺序、家族；英文题干及题型指令；逐题记录摘要；所有来源文件摘要；35 条来源重新定位抽取；703 对词汇相似度筛查。DOCX 依据 `word/document.xml` 中所有 `w:p` 的 1-based 顺序定位，包括空段与表格段，要求题干前一段为“原题”。Markdown 按行号，JSON 按数组键定位。

所有 35 条有来源题均重新定位成功，32 条原文摘录与来源仅做空白规范化后相等。近重复判断与标签为本次编制者内容审阅，词汇相似度不能代替语义审查；未做独立考官审校。没有渲染或检查 DOCX 版面，本次验证限于 XML 文本与来源摘要。后续正式上线仍需内容校审与检查点资格实现。
