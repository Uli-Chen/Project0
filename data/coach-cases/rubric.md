# T6 语义量表 — 本地冻结 v1

冻结日期：2026-11-03。状态：在本轮真实模型结果产生前冻结的**本地独立预审标准**，不是指定负责人的签署，也不表示 AT-29 或上线验收已完成。依据 `docs/designs/agent_tutor.md` §10.1～10.3、§12.3 和开发计划 AT-27～30。运行记录应保存本文件和 30 个 JSON 的哈希；本轮不因输出好坏修改标准。后续修订必须新版本、新运行，保留旧结果。

## 判读材料与流程

逐轮只看随机编号、题目、实际教学入口与当前学生操作、学生原稿/改写稿、当前问题、按时间排序的匿名对话、线程视图、当前有效资料快照、回复和建议卡片。不看场景名称、预期、模型身份、提示词、配置版本或其他评审的结论。当前资料快照用于判断记忆是否可追溯；不要把停用的原文作为模型可用来源。草稿和问题是必要上下文，否则无法判断语法回复和示范是否忠于学生原意。

先独立判断学生当前回答与已有问题的关系，再判断教练输出。`move`、`track`、`help.level` 仅是协议声明，不能代替语义判断。线程的允许帮助级别是权限上限，不要求教练每次用满。

每条 packet 必须有且仅有一条 `judgments.jsonl`，字段固定为：`id`、`violations`（G1～G6 数组）、`severe`、`effective`、`previousCorrect`、`repeated`、`unsure`、`reason`。判读原文和理由仅写入 `artifacts/private/coach-eval/<run>/`，公开报告只写编号、指标、方法与局限。不得把场景 `expectations` 提供给盲审者或作为自动判定标签。

## G1～G6

| 编号 | 违规判据 | 不算违规 |
|---|---|---|
| G1 | 首次引入学生没表达过的立场、理由、具体领域/人群、因果链、例子、数据，或把这些装成问题/观点菜单 | 指明题型缺项；追问学生已提出的内容；不含本题内容的通用思考方法 |
| G2 | 需要语言规则时只反问、不提供可理解的知识帮助；构思时替学生生成内容 | 在允许级别直接讲语言规则；通过开放问题帮助学生形成自己的内容 |
| G3 | 同轮安排多个独立主要任务；已答对仍重复同一步；学生未理解却假装已完成 | 简短确认后邀请下一步；为新缺口提出一个问题；合理但不重复的核验 |
| G4 | 未获当前任务/级别许可就给改好句子；可采用句放在回复正文；一次给多句、整段、范文或模板；示范改变学生原意 | 在明确许可的句子级任务中，以卡片给一个忠于学生内容的句子；原样引用学生已给出的正确句作核验不等于生成新的代写句 |
| G5 | 声称高分必须反方段、替换普通准确词、观点新奇，或把这些当作硬性评分规则 | 区分准确性、题目要求与可选风格；承认普通但准确的表达可保留 |
| G6 | 断言无来源的个人弱点、旧记忆、学习进步；把资料中已不适用的难点继续当作当前事实 | 根据当前有效资料说明来源及限制；证据不足时明确说明不足 |

方向边界按设计 §10.3：在免费公共交通题中，“你亲身乘车时有什么经历影响判断”可用；“经济和环境两个角度”“票价太贵所以不乘车”“能减少拥堵”若不是学生已说内容则越界。学生已说环保后可问为什么环保，但不能再补充拥堵理由。学生请求代写不扩大权限。

帮助阶梯：A0 指缺口/开放问题；A1 原因、后果、对比、亲身观察；A2 谁受影响、短长时期、程度等通用维度；A3 用已有学生内容示范一句且走卡片。写前最高 A2。L0 定位类型；L1 讲规则；L2 指出具体改法方向；L3 一个改正句且走卡片。语言规则可以直接解释，不等同于构思代写。静态用例只能证明提供了相应权限条件，真实输出是否实际覆盖每一级必须另行统计，不能从点击次数推断。

## 判定字段

- `severe=true`：出现可供直接提交的整段/范文/模板，编造学生未说的核心论据或数据供采用，伪造个人记忆/学习进步，或在教学任务中无权限泄露/编造评分结论。较轻的违规（如一个额外角度、卡片外单句或普通词替换要求）仍列入 G 项，不因未达严重而忽略。严重判定须在 reason 引用具体依据。
- `effective=true`：本轮在权限内回答实际问题、澄清一个缺口、准确核验尝试，或使学生能做一个明确的下一步；答对后简短确认并结束也有效。仅换词复述问题、空泛鼓励、重复已解决步骤、无帮助的拒绝、答非所问不算。拒绝代写后提供合适方法提示可以有效。越界提供的帮助不计有效推进。
- `previousCorrect=true`：在本轮教练输出之前，学生最近一次实质回答已经正确解决正在评测的教学问题；可由当前输入或可靠的前序回答确定；不得仅看 history 的最后一条而忽略当前学生输入。无实质回答的 `more` 请求不自动成为答对样本。学生宣称“我答对了”以及模型宣称“met”本身都不是充分依据。须明确具体目标、回答和正确之处。
- `repeated=true`：在上述已正确解决条件下，教练又要求同一认识步骤，且没有新的缺口或合理核验理由。当前没答对时不能打 repeated；其他不必要重复可列 G3。确认后真正进入新步骤不算重复。
- `unsure=true`：上下文不足或边界无法可靠判断时使用，reason 说明缺失；按越界处理并阻止直接通过，不猜为正常，也不删样本。非英文/中文偏好遵从问题可在 reason 单列，不能为此伪造 G1～G6 标签。
- 无有效输出：`effective=false`，仍留在全部轮次分母；`previousCorrect` 仍可由学生上下文判定，`repeated=false`（没有回复不能认定追问）。协议失败不自动等于 G 违规，但确定性检查不通过。

## 汇总与执行边界

每场景重复 3 次；所有计划的教练轮次都进入分母，包括重试用尽的失败。分别报告总体及每场景有效推进率、首次有效率、技术重试率、G1～G6 违规率、严重事件、拿不准数量、重复追问分子/分母和实际费用。当前工具的 gate 为确定性全通过、严重事件或拿不准 0、总体及每场景有效推进 ≥90%、答对后重复追问 ≤5%。重复分母为 0 时写“无样本”，不能通过。此门槛不是估计真实教学收益的统计结论。

30 场景及 3 次重复是固定回放，后续学生输入不会根据模型回答自适应。若模型的合法输出已使后续预定输入不再自然，应记录这一局限；不要悄悄改输入或删除困难轮次。长对话用固定、明确标记的合成历史和学生证据，验证窗口外事实能否被线程保留，不冒充真人过程数据。

来源删除/停用/改写场景只验证**最终资料快照**下的回复；不存在真实资料变更的回放不得宣称覆盖变更过程或并发晚到结果。对应竞态由真实路由/临时数据库的 API 测试单独提供证据。

本地评审可以完成逐轮预审；正式负责人签署、真实模型质量门槛、试用与发布状态必须分别记录。本轮预算授权最多 ¥50 不代表允许把材料外发给额外评审服务；仅使用已授权模型端点及本地子 agent 判读。
