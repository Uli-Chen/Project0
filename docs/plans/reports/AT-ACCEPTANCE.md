## 最终真实模型结果

固定30场景×3次，共216轮。第六轮全量初判后，独立复核79条（疑似违规全量、通过项21/206、7个关键场景54轮，范围有重叠），13条分歧交新agent裁决。全部原始判定和合并依据保留。

| 指标 | 最终本地复核结果 |
|---|---|
| 结构与权限 | 216/216有效，215/216首次有效 |
| 有效推进 | 208/216，96.30% |
| 保守敏感性检查 | 将任何G违规都视为未推进：204/216，94.44% |
| 答对后重复追问 | 2/48，4.17% |
| 已确认严重事件／拿不准 | 0／0 |
| 含至少一项G违规 | 12/216；仍需改善，不能以总体达标掩盖 |
| 解释语言偏离 | 人工核对216条，0条 |
| 本地额外逐场景门槛 | 未通过：case-03、case-07、case-17低于90% |

主评测实际未产生A3示范卡片，另用独立冻结补充集验证中英文各3次；6/6实际提供只用学生既有内容的一句论证示范，两位独立审查者全量判断一致，无违规。补充结果不计入或替代216轮主成绩，答对分母为0，不能独自作为整体质量通过证据。

六轮主评测及补充合计1379次实际尝试，保守计费 **¥14.533464／¥50**。使用用户明确授权的当前配置，逐次预留，复跑扣除此前费用，不在每轮重置上限。只调用已授权的模型端点；用户选择先完成本地审查，没有调用外部Claude审查服务。费用依据、历史失败与私有证据路径详见 [T6报告](AT-T6.md)。

## 剩余事项与当前状态

- **负责人验收：** 按用户指示先完成本地审查；原设计指定负责人的正式语义判定和签署尚未完成。独立抽查不能冒充指定负责人的签署。
- **真人试用：** 由创始人安排3～5位真人各自完成完整练习；合成账号、假模型和固定回放不算试用者。
- **隐私发布条件：** 联系邮箱、备份与服务器日志保留期、供应商条款等P-2待补齐。90天调用内容清理为启动/写入触发，不承诺空闲服务恰好第90天物理删除。按原计划，P-5法务事项也属于免费试用条件，不由本地代码测试代替。

`TUTOR_V2_ENABLED`默认关闭。关闭只影响新请求，已经冻结为v2的同requestId恢复仍按快照，这是方案规定的回滚边界。测试服务已停止，临时数据库留在/tmp。未执行生产部署、备份清理、真实用户数据评测或提交；工作区可供负责人审阅。
