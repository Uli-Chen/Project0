# AT-T4 教学动作与卡片集成报告

prewrite / issue 使用动态协议schema，在解析时预演原子增量；其他6入口保持旧输出结构但走新准则。写前“给点提示”当轮提升临时上限，成功才保存，hint 不作为观点证据；失败后不丢学生文字。问题线程支持局部确认、达标关闭、重新打开、不同问题隔离与开→关→开旧路径对齐。

三级示范走 example 卡片，服务器生成id/status/type；反馈阶段仅可忽略、改写阶段可插入，采用沿用既有AI文字占比计算。帮助事件覆盖8入口并裁剪至200，nudge无提醒不记事件。调用记录写 move、权限上限、实际帮助与语义告警。

tests/tutor-runtime.test.ts、tutor-api.test.ts、tutor-thread.test.ts 与 tests/ui/tutor-feedback.test.ts 验证协议重试、原子性、hint引用、采用权限、恢复及界面。浏览器实际结果和局限见 [统一验收](AT-ACCEPTANCE.md)。这些结果不证明真实模型没有重复追问或越界代写。
