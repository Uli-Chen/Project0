# 深入体验修复：精练生命周期入口

2026-11-01。仅修改本地 Deep 客户端与必要回归，未修改服务器真实数据或生命周期接口。

## 行为

- 更多菜单提供“保存并暂放”“关闭这次练习”；关闭有说明与确认。暂放/关闭显示状态条和“恢复练习”，避免主题推荐引导暂放但无入口处理。
- 生命周期转换与已有 PATCH 保存串行：冻结本地新编辑，清除待触发自动保存，先 flush 未保存草稿/提纲，再 POST 生命周期。保存失败/冲突阻止状态转换，保留本地正文；网络失败不做乐观切换。
- 模型处理和状态转换期间互相禁用；非 open 的正文只读、教练与评价写操作不可用，恢复后可继续。教练输入框保持挂载以保留未发送输入（与另一个代理协调同文件实现）。
- 检查点明确提示暂放不暂停40分钟；关闭后恢复不会重新取得资格。显示用时按服务端创建时间的连续墙钟推算，刷新/暂放不会重置；资格仍只由现有服务端判定。
- 面包屑“作文”返回 `/essays`；离开仍先保存。双问题提纲的 questionType 传入按其他代理提供的显示协议，不改评分输入。

## 验证

- UI 静态回归新增：暂放/关闭恢复入口、检查点资格/计时文案、操作中disabled、关闭/暂放正文保留但没有textarea、教练能力恢复。
- 中间集成验证 UI 33/33、业务 173/173，lint/typecheck 通过；整合其他代理的提纲/教练显示后由根代理再验收。
- 浏览器最终验收由根代理执行：输入草稿立即暂放、恢复保留；关闭确认/恢复；失败保存不切状态；模型忙时不可切换。

范围：session-store、essay-view UI helper、essay-screen/topbar/body、DeepLifecycleBar、feedback/compare写操作禁用及测试。未更改 Quick、题库/主题页或服务器数据。

整合题型显示与教练面板改动后，最终 typecheck/lint 通过，UI 38/38。教练 Composer 沿用原组件语义：disabled 阻止发送但不销毁其本地输入，暂放/关闭后恢复不会因卸载而丢失未发送文字；正文编辑与服务器写操作均禁用。日志保存在同名目录。

## 交叉审阅补修：服务端闭锁与未发送文字

- Deep PATCH、新动作和独立 review retry 的预留入口增加生命周期 open 检查；放在已完成请求/写请求幂等重放之后。暂放/关闭的新请求返回 409 lifecycle_conflict，正文、版本和模型调用不变化。resume/close 端点及后台结果提交仍可用。
- 没有在通用 saveSession 或后台 review 提交阶段添加 open 限制，避免用户暂放后丢掉已在途的回顾结果。现有真实路由用例“自动回顾保留较新的暂放状态与时间”继续通过。
- Composer 未发送文字提升为 SessionProvider 的独立内存字段，条件卸载/重新打开面板仍能保留。它不进入 PATCH、不冒充聊天记录、不计入“可由服务器保存”的 hasUnsaved。
- beforeunload 同时保护草稿和未发送文字。页面链接（包括完成弹窗中的链接）统一捕获：存在未发送文字时，显示页面内确认和可复制的文字，明确不会随作文保存；用户选择继续时先保存作文，失败不离开，成功后才舍弃未发送文字并导航。新标签打开不会销毁原页面，未被拦截。
- 生命周期状态条与关闭确认明确说明：保存作文不等于保存未发送的教练文字。没有使用 window.confirm。

必要增量：session-api/practice-api 17/17；UI 39/39；lint/typecheck 通过。API新增两种非open状态下全部Deep动作与PATCH拒绝、零写入/零模型、幂等回放允许、恢复后保存可用；UI新增准确离开文案及保存中按钮禁用。浏览器互动最终由根代理验收。
