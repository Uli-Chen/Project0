# 作答与提交

版本：0.2-draft。维护：AG-PLAN 起草，创始人批准。基线来源：原方案 §2、§3、§4.2、§6、§7。关联决策：[ADR-001](../decisions/001-mvp-scope.md)。

## 目标与范围

成年邀请用户选择一题雅思 Task 2，在 Web 编辑器完成独立初稿。MVP 使用少量来源明确的原创或授权题目，不支持自选考试、图片输入或外部题目上传。

## FLOW-001 — 身份与进入练习

- 服务端识别用户；邀请认证具体实现由 MVP-001 确定，不能使用前端传入的 user_id 作为可信身份。
- 记录成年确认、服务/隐私同意版本和时间；未完成不能提交到模型。样本用于模型改进的授权独立且默认关闭。
- 页面展示题目、目标任务、数据处理说明和“AI 实验性预估”。首次完整闭环免费，不展示 LT 余额或购买入口。
- 无目标分、考试日期时仍可练习；MVP 不生成长期诊断或声称已了解用户长期弱项。

## FLOW-002 — 编辑、计时与恢复

- 输入后 1 秒空闲触发本地草稿持久化；写入成功才显示“已保存到本机”。本地写入失败明确提示并允许复制导出。
- 联网时最多每 5 秒同步服务端草稿；本地即时保存不依赖联网。显示最后成功保存状态。
- 限时练习参考 40 分钟，超时可以继续；不自动提交。提交前显示实际时长和字数，低于目标字数不自动拒绝。
- MVP 字数口径：由同一版本规则统计英文 token（含词内撇号、连字符），前后端使用同一组样例验证；不宣称等于官方内部算法。
- 页面刷新或断网后恢复最近成功保存内容和计时。存储不可用时不得宣称“断网不丢稿”。不支持跨设备离线合并。
- 同一草稿多标签编辑使用 revision/ETag 冲突检测；冲突时保留双方副本并要求选择，不静默覆盖。
- 退出账号清除该用户的本机草稿缓存；新账号不能读取前一账号内容。

## FLOW-003 — 不可变提交

- 提交前保存当前内容快照；服务端返回 submission_id、evaluation_id 和状态查询地址。
- 提交后正文不可修改，后续改写产生新 submission。句子编号绑定文本快照和分句版本，禁止引用可变草稿。
- 空白、只有题目复制、明显非英语等输入返回可操作原因；技术上限暂定 20,000 Unicode 字符，不是考试字数限制。越限拒绝且不调用模型。
- 空白与长度校验提交前执行；语义类不可评分判定可在处理后返回 `not_scorable`。不将这些情况编造成低分。
- 超时重试复用同一幂等键；同一键不同正文返回冲突，不覆盖第一次提交。

## 数据与边界

Draft 是可变对象；Submission 是不可变快照。题目版本、内容哈希、草稿 revision、作答时长、辅助来源和 pipeline 归属均按 [契约](contracts.md) 记录。用户手动粘贴不等于作弊；本阶段不推断或标记“AI 代写”。

## 验收与假设

验收：AC-001、AC-002、AC-003。任务：MVP-001、MVP-003、MVP-004。

待验证：邀请入口与编辑器是否足够易用；40 分钟提示是否妨碍首次体验。不得用页面访问量替代实际提交数。
