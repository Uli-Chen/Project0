## 1. 一句话

学生今天用十五分钟改好一个重要问题；下次回来，系统知道该继续帮他，还是让他独立试一次。

为此做三件事：

1. 把写作拆成可以单独练的环节，日常练习用 10～15 分钟的小单位，整篇是定期的合成与检验（§5）。
2. 说清楚什么算学会，每次任务都区分“自己做到”和“帮助后做到”（§6）。
3. 用一条确定的规则决定今天做什么（§7）。

首轮只做一个论证目标上的完整闭环（§8）。其余功能放在候选池，各自写明采用前要满足的条件（§9）。

## 2. 设计方法

### 2.1 从难点出发

速刷卡片是这样设计出来的，后面每个功能都按同一张表推导：

| 步骤 | 速刷卡片的例子 |
|---|---|
| 难点 | 40 分钟里，一边想内容一边找英文，两头都做不好 |
| 认知上的原因 | 工作记忆有限。用第二语言写作时，把意思转成句子占用的注意力比母语多，留给构思的就少 |
| 对应的机制 | 把构思和转写分开；先用熟悉的语言把内容定下来 |
| 练习形态 | 一张按题目要求分栏的卡片，中文或英文都可以写 |
| agent 做什么 | 一次问一个问题，不代写；检查每个小问是否有回答和理由 |
| 怎么验证 | 用卡片写成的作文，“跑题或回答不全”是否更少 |

### 2.2 agent 在这里比固定程序多做什么

| 能力 | 用在哪里 | 约束 |
|---|---|---|
| 读懂一段自由文本里的理由和支撑 | 核验、标注（§8.2、§8.3） | 只能指到学生原句，不补内容（G1） |
| 根据学生刚说的话决定下一个问题 | 现有写前追问；段落练习里的一个问题 | 一轮只推进一件事（G3） |
| 判断解释是否真的成立 | 核验（§6.2） | 需要行为评测集（§8.1） |
| 跨练习记得证据 | 本篇重点、新题检验 | 记忆从证据重算，见 agent_tutor §9 |
| 调节帮助多少 | 帮助阶梯（已有） | 帮助事件全部记录 |
| 用学生听得懂的话讲规则 | 语言问题的讲解；连续失败时的直接讲解 | 语言知识可以直接讲（G2） |

### 2.3 证据等级

系统记录到的东西，按它能确认什么分等级。等级低的只能展示，不能改变排期或学习状态。

| 记录 | 能确认 | 不能确认 |
|---|---|---|
| 学生把自己的审题条目连到题库小问 | 学生认为它们对应 | 是否真的理解，有没有连错 |
| 表达库条目与新原稿词干匹配 | 这些词可能出现过 | 是否用对，是否自己想起来的，是否掌握 |
| 原句被植入一处变化 | 文本只有一处不同 | 原句本身正确，改法只有一种 |
| 输入和分段的时间点 | 何时输入，何时出现段落边界 | 何时在构思或检查，为什么停顿 |
| 模型核验“做到 / 没做到” | 在评测集覆盖的情形下，判断大体可靠 | 评测集以外的情形 |

## 3. 难点分析：6 分到 7 分卡在哪里

第三列是对雅思公开评分标准的转述，已对照公开版原文核对（§15）。

| # | 难点 | 在评分里的表现 | 现在靠什么 | 缺口 |
|---|---|---|---|---|
| D1 | 没想法，或想得慢 | 任务回应：观点少、离题 | 速刷卡片 | 基本覆盖 |
| D2 | 有想法但展不开：理由停在断言、推理跳步 | 任务回应：6 分是有相关的主要观点，但有些展开不足或不清楚；7 分是主要观点得到展开和支撑 | 写前追问 | 没有可以反复练“展开”的小单位，只能靠整篇作文顺带练 |
| D3 | 审题不全，立场前后不一致 | 任务回应：6 分是各部分回应得不均衡；7 分是回应题目的每个部分，立场贯穿全文 | 卡片由题库把题目拆成小问 | 拆题是系统替学生做的 |
| D4 | 中文想好了，英文说不出来 | 词汇：7 分要求用词有一定的灵活和准确，有搭配意识 | “英文怎么说”和表达库 | 给了就用，下次还是不会 |
| D5 | 同一类语法错误反复出现 | 语法：6 分是有一些错误但很少影响理解；7 分是无错误的句子频繁出现；8 分才是多数句子没有错误 | 错句本 | 练的是旧句子；学生不会自己查错 |
| D6 | 衔接机械 | 连贯：6 分的描述包括句内或句间的衔接有误或机械 | 无 | 暂不处理，原因见 §14 |
| D7 | 写不完 | 四项都受影响 | 无 | 问卷里有这个选项，但没有任何功能对应 |
| D8 | 分不清好段落和一般段落 | 改不动自己的文章 | 反馈 | 暂不单独处理，原因见 §14 |

问卷里的五个难点选项和上表的对应：没想法 → D1；想法说不清 → D2；英文表达不出来 → D4；语法错误多 → D5；写不完 → D7。

## 4. 学习机制

这些研究多数来自课堂和实验室，对象也常常不是成人二语学习者。用到本产品上属于推断，要靠 §11 的指标检验。每条的核对状态见 §15。

| # | 机制 | 研究结论 | 对设计的含义 | 适用边界 |
|---|---|---|---|---|
| M1 | 拆开认知负荷 | 写作同时进行构思、转写、检查，三者争抢注意力。先列提纲的人写得更好，因为动笔时可以专心把想法写成句子 | 一个练习只练一个环节 | 研究对象是母语写作者 |
| M2 | 小单位、有目标、可重复 | 进步来自针对一个弱点的练习，马上有反馈，可以重复。青少年写作教学的元分析里，“给出明确的成品目标”效果较大 | 段落练习；一段时间只盯一个重点 | 元分析对象是美国四到十二年级学生 |
| M3 | 先自己生成，再看答案 | 自己回忆或尝试过的内容，比读到的记得更牢。被迫产出时，学生才会注意到想说的和能说的之间的差距 | 默认先试后给；复习是产出，不是重读 | 学生缺少必要知识、连续失败，或明确要求解释时，应当直接讲 |
| M4 | 反馈指向任务，不指向自我 | 反馈平均有正效果，但超过三分之一的反馈干预降低了表现；注意力被引向自我评价时效果变差 | 反馈先说要做什么；分数退后 | 分数与评语的经典研究对象是小学生，高分学生是例外 |
| M5 | 间隔、变式、撤支架 | 分散练习优于集中练习；在变化的材料上练才能迁移；帮助要随能力提高而撤掉；练习条件越接近考试条件，考试表现越好 | 换题再做一次才算数；帮助跟着能力减少 | 撤除的时机要看证据，不能看次数或日期 |

v0.1 里有两条已删去或改写：

- “集中纠正少数几类错误比全面纠错有效”：元分析没有发现两者有显著差异，另有研究发现全面纠错同样有效。所以“一次只推进一个问题”的理由是降低学生采取行动的成本，不是纠错研究的结论。
- “单独讲语法是负效果”：原研究指的是面向青少年的传统语法教学，不能用来说明成人二语学习。

## 5. 训练方式

下面这条线是**能力分解图**，说明写一篇作文用到哪些环节。它不是每个学生都要走的流程：

审题 → 构思 → 把意思转成英文 → 展开成段 → 合成整篇 → 限时独立完成

对应的训练方式可以单独使用，由 §7 的规则选择：

| 训练方式 | 时长 | 学生做什么 | 结果 | 状态 |
|---|---|---|---|---|
| 复习 | 最多 5 分钟 | 回忆表达、改句子 | 排期 | 现有 |
| 卡片 | 10 分钟 | 写每个小问的回答和理由 | 通过 / 还需展开 | 现有 |
| 段落 | 15 分钟 | 针对一个重点写一个主体段 | 这一点做到 / 部分 / 没做到 | 新，首轮 |
| 最小修改 | 5～15 分钟 | 改好上次反馈里的一个问题 | 这个问题解决 / 部分 / 没解决 | 改，首轮 |
| 整篇 | 40 分钟 | 写完整作文 | 分数与问题 | 现有 |
| 独立模考 | 40 分钟 | 没练过的题，没有教练 | 独立成绩 | 现有 |

规则：

- 一个审题和构思已经不错、主要卡在语法上的学生，不必先做卡片。已经有完整作文的学生，直接进入最值得修改的部分。
- 段落不给总分，一段文字评不出四项分数。
- 相同词数的短段落不能替代整篇。整体构思、跨段组织和时间分配只有整篇能练。
- 按模考条件写，不等于合格的独立模考。练过的题、有卡片的题、写过段落的题，仍然不进入独立成绩，现有的资格规则不变。

## 6. 学习成果怎么判定

### 6.1 每次任务记三件事

1. **首次尝试的结果**：学生在看到任何针对这一点的帮助之前提交的那一版。
2. **之后用过的帮助**：标注、追问、提示，各记一条帮助事件。
3. **最终核验结果**。

图表和进展页默认只用首次尝试的结果。帮助后的成功单独显示。

### 6.2 核验标准

核验问的是：**这段文字有没有说明理由为什么成立，以及它如何支持对题目的回答。**

- 有一句形式上的解释，不等于做到。“这很重要，因为它带来很多好处”仍然是没做到。
- 展开方式不限：原因、后果、比较、条件、反例都可以。一句话可以同时是主张和解释。例子不是必需的（G5）。
- 核验时读入题目。核验修改时读入必要的全文，避免这一段变好了，却和全文立场冲突。
- 结果有五种：做到、部分、没做到、没有机会、拿不准（沿用 agent_tutor §9.4 的 `focusResult`）。“没有机会”和“拿不准”不进入任何比例。

### 6.3 四种成果

| 成果 | 条件 | 对应 agent_tutor §9.2 | 能用来做什么 |
|---|---|---|---|
| 行为记录 | 出现、点击、用时 | 无 | 只展示 |
| 帮助后做到 | 看过标注、追问或提示之后的尝试核验达成 | 针对性辅导后做到 | 本次任务完成，不算进步 |
| 知道重点后做到 | 预告了重点，首次尝试达成，之前没有针对这一点的帮助 | 知道重点后做到 | 可以安排新题检验 |
| 新题未提示做到 | 新题，不预告重点，没有针对性帮助，首次尝试达成 | 未提示的新题迁移 | 重点可以退出 |

学生自己的卡片是他的素材，不算针对性帮助。但新题检验用的是没有卡片的题。

## 7. 今天做什么

### 7.1 输入

- **今天有多少时间。** 默认用问卷里的单次时长，首页可以临时改成 10、20 或 45 分钟。
- **上次留下的任务。**
- **当前重点和它的证据。**

每一项都必须能在今天做完，并留下一个结果。放不下的不排。只有 10 分钟时，只排一项。

### 7.2 优先顺序

从上到下，排到时间用完为止。

| 顺序 | 任务 | 条件 | 过期规则 |
|---|---|---|---|
| 1 | 继续没做完的练习 | 学生上次中途停下 | 7 天后不再置顶，留在作文列表里 |
| 2 | 上次反馈留下的修改 | 有反馈，还没改 | 反馈 7 天后不再推荐，仍可进入 |
| 3 | 到期复习 | 有到期条目 | 封顶 5 分钟，其余顺延 |
| 4 | 接续 | 卡片已通过，还没写 | 写这道题的段落，不换题 |
| 5 | 新题检验 | 重点满足 §7.4 的检验条件 | 无 |
| 6 | 本周整篇 | 本周还没写整篇，今天有 45 分钟 | 无 |
| 7 | 新练习 | 以上都没有 | 按 §7.3 选训练方式 |

修改排在复习前面，因为反馈放久了学生会忘记当时的想法，而且修改是主要的学习环节。这是初值。

做完清单显示“今天完成”和下一次的预告，不再推荐下一篇。学生可以随时换题或自己选练习，规则只决定默认值。

### 7.3 选哪种训练方式

分类表校准之前没有可靠的瓶颈证据，先用学生自评的难点：

| 自评难点 | 默认训练方式 |
|---|---|
| 没想法 | 卡片 |
| 想法说不清 | 段落 |
| 英文表达不出来 | 现有的“英文怎么说”；搭桥采用后改为搭桥（§9.1） |
| 语法错误多 | 现有的错句本；找错采用后改为找错（§9.3） |
| 写不完 | 整篇后的用时观察（§9.5） |

分类表 v2 校准通过后，改用 agent_tutor §9 的证据。

### 7.4 重点的进入、检验和退出

- **进入：** 首轮只有一个固定的论证目标（§8.1）。之后按 agent_tutor §9.4 的规则选。
- **检验：** 同一重点在不同的题上“知道重点后做到”2 次后，下一次安排新题检验：新题，不预告重点，不看卡片，不给针对性帮助。
- **退出：** 沿用 agent_tutor §9.3 的 `improving` 条件。段落级的新题检验能不能算作其中的证据，见 §12 第 6 项。
- **次数和日期只能触发一次尝试**，不能当作已经具备升级条件。检验没做到，就回到有预告的练习。

### 7.5 连续失败

同一重点连续 2 次首次尝试没做到时，第 3 次不再重复同样的任务：

1. 换一种帮助方式，不自动升级帮助级别（agent_tutor §10.2）。
2. 教练直接讲一次这个目标要求什么，并用学生自己的一句话示范（A3，只能一句，走建议卡片）。这是“先试后给”的例外。
3. 换成学生已经有卡片的题，降低内容上的难度。

仍然没做到，暂停这个重点，进展页如实显示，不标成已完成。

## 8. 首轮核心

首轮只回答一个问题：**学生能不能更快完成有效的修改，并在新材料上再次做到。**

### 8.1 一个论证目标和它的评测集

- **目标：** 理由有没有说明为什么成立，并支持对题目的回答。它对应 D2，也是 agent_tutor §2 排在第一位的用户需求。
- **为什么先建评测集：** 整个首轮都依赖模型对这一点的判断。速刷检查曾经把循环论证判为通过（[WP5_coach_behavior.md](../plans/reports/WP5_coach_behavior.md)）。
- **评测集要覆盖的情形：**

  | 情形 | 期望 |
  |---|---|
  | 用原因、后果、比较、条件或反例做了有效解释 | 做到 |
  | 一句话同时是主张和解释 | 做到 |
  | 语言错误多，但逻辑成立 | 做到 |
  | 循环论证 | 没做到 |
  | 空泛的解释（很重要、有很多好处） | 没做到 |
  | 只有例子，没有说明例子为什么支持理由 | 部分或没做到 |
  | 解释本身成立，但不支持对题目的回答 | 没做到 |
  | 语言流畅，但逻辑是空的 | 没做到 |
  | 段落太短或与题目无关 | 没有机会或拿不准 |

- **做法：** 沿用 agent_tutor §12 的评测方式和工具。样本先由负责人编写，通过门槛由 owner 确认，之后请雅思教师复核。这是首轮的第一项工作。

### 8.2 段落练习

- **学生看到的：** 题目，一句“这次只看一点：理由要说明为什么成立”。写一个主体段，80～110 词。提交后几秒内看到结果和标注（§8.3）。
  - 做到：结束，或者换一道题再写一次。
  - 没做到：教练提一个问题。学生修改后再核验，这一次记为帮助后的结果。
- **agent 做的：** 按 §6.2 核验，指到句子；没做到时提一个不带内容的问题（agent_tutor §10.3）。语言问题最多提一处。
- **代码做的：** 区分首次尝试和帮助后的尝试；记录帮助事件；校验句子编号。
- **卡片：** 有卡片的题，卡片可以展开查看。新题检验用没有卡片的题。

### 8.3 理由与支撑的标注

- **学生看到的：** 在自己的原文上，理由句和支撑它的句子被标出来，旁边一句话说明两者的关系类型，例如“这句在说后果”。
- **不做的：** 不显示固定的格子，不显示空位，不要求凑齐某种结构。只有核验认为存在逻辑缺口时，才提一个问题。
- **学生可以改标注**，例如“这句是在解释，不是另一个理由”。
- **agent 做的：** 只标注学生的原句，只说关系类型（agent_tutor A1 允许的范围），不补内容。

### 8.4 最小修改

修改的范围由问题决定，默认是**解决这个问题所需的最小修改**：

| 问题涉及的句子 | 默认范围 |
|---|---|
| 一句 | 改这一句，例如主谓一致 |
| 同一段里的几句 | 重写这一段，例如推理跳步 |
| 跨多个段落 | 列出涉及的段落一起改，例如立场前后冲突 |
| 漏答题目的一部分 | 补一段或调整结构 |

- 范围由代码根据问题引用的句子编号计算，学生可以扩大。
- 核验只看这个问题有没有解决，同时读入题目和全文。
- 不再给全文重新打分。学生选“改全文”时保留现在的流程。

### 8.5 接续

这是首轮的前提，不是新功能：

- 卡片通过后，下一次默认写这道题，不换题。
- 反馈之后，下一次默认做这篇的修改。
- 每个问题的核验状态和帮助来源都要记录下来。帮助事件的记录已在 agent_tutor 第一阶段实现，随 `TUTOR_V2_ENABLED` 默认关闭。

审查提到之前发现过卡片接续和反馈接续的具体断点。那份清单我没有见到，补上之后写进这一节。

### 8.6 今天的清单和完成状态

按 §7 实现。

## 9. 候选池

以下功能保留为候选。每项写明现在能确认什么，以及采用前要满足的条件。

### 9.1 搭桥

- **针对：** D4。
- **做法：** 卡片通过后，学生从卡片里选几处想用英文说的意思，每处先用自己会的词写一遍，教练再回应。学生的写法能表达意思时，先说它可以用，再给更准确的说法。
- **边界：** 可以跳过。只对自评“英文表达不出来”或写中求助多的学生默认出现。
- **采用条件：** 首轮证明段落练习有效之后。

### 9.2 自己审题

- **针对：** D3。
- **做法：** 做过几张卡片后，某一张先让学生自己写“这道题要回答哪几件事”，再显示题库的小问作对照。
- **边界：** 学生自己把条目连到题库小问，这只代表他的看法，只用于展示对照。次数只触发一次尝试；漏了小问，下一张恢复为系统拆好。
- **采用条件：** 无模型依赖，可以随时做，但不在首轮范围内。

### 9.3 找错

- **针对：** D5。
- **做法：** 用学生自己的句子，植入他常犯的一类错误，让他找出来并改正。
- **边界：** 只用核验过的句子；学生只能改指定范围内的词；接受所有合理的改法。例如 `Students benefits` 改动词或改主语都算对。先只做答案可以列举的类型，例如主谓一致。
- **“只告诉数量”的形式暂缓：** 它依赖诊断数得准。
- **采用条件：** 分类表 v2 校准通过；owner 确认植入错误的句子在 G4 允许的范围内。

### 9.4 表达出现提示

- **针对：** D4。
- **做法：** 新原稿的反馈里提示“这篇出现了你积累的 3 个表达”，并标出位置。
- **边界：** 只提示，不说“学会了”，不自动改变复习间隔。原因有三：表达在写作时可能就显示在旁边；出现不等于用对；现有的词干函数只是粗略的词语集合。
- **以后升级的条件：** 能核验这次使用是否恰当，并且能区分有提示的使用和独立使用（例如独立模考里的使用）。

### 9.5 用时观察

- **针对：** D7。
- **做法：** 整篇和模考提交后，显示每一段从开始到结束的输入时间线。
- **边界：** 只显示输入发生在什么时候，不推断学生在构思还是检查。
- **采用条件：** 无模型依赖，可以随时做。限时段落（10 分钟写完一段）的研究依据多数来自口语，等用时数据说明确实有人需要再做。

### 9.6 写后的自我反思

- **针对：** D8。
- **做法：** 提交后等待评估时，可以选一下“你最担心这篇的哪一方面”。反馈显示：“你最担心语法；教练建议这次优先处理论证，原因是……”。
- **边界：** 可以跳过。两者不一致不代表学生判断错了，可能只是优先级不同。不统计一致率，不把它叫作判断力。
- **采用条件：** 评分诊断校准之后再考虑做成训练。

### 9.7 临考的独立任务比例

- **针对：** 考场上没有教练。
- **做法：** 考试日期只调整任务的比例：离考试越近，“今天”里限时的、完整的、独立的任务越多。
- **边界：** 不按日期关闭教练入口。某项技能的帮助给多少，由该技能的证据决定（agent_tutor §9、§10.2）。两周后考试但还不会展开理由的学生，仍然需要帮助。
- **采用条件：** 帮助事件的技能归因完成（agent_tutor 第二阶段）。

## 10. 学生看到的工作流

只写和现状不同的地方。

1. **第一次来：** 先问目标分和考试日期。然后二选一：“贴一篇你写过的作文，看诊断”，或者“从一张卡片开始”。贴来的作文不知道写作条件，只用来找第一个值得改的问题，不进入成绩趋势。
2. **今天：** 一份短清单和总时长，做完有完成状态。
3. **反馈页：** 第一屏是最影响分数的一个问题、原句、改写方向和修改按钮。
4. **进展页：** 每个重点的记录，分开显示首次尝试、帮助后做到、新题未提示做到。其次是独立模考成绩。
5. **配额：** 追问和检查的次数放宽到正常使用碰不到；碰到时引导去写，不显示计数。

> **示意。** 小林的重点是“理由要说明为什么成立”。
>
> 周一她有 20 分钟。清单是一项修改和三条复习。上周那篇的第三段被指出理由没有解释，修改范围是这一段。她重写后核验为解决，记为帮助后做到。
>
> 周三她有 45 分钟。清单先接续上周通过的卡片，写这道题的一段。提交后首次尝试就判为做到，标注显示第二句在说后果。她又换了一道题写了一段，也做到了。
>
> 周五，清单里是一道没练过的题，没有预告重点。她写完，核验为做到。进展页上这个重点多了一条“新题未提示做到”。
>
> 周末她写本周的整篇。

## 11. 怎么验证

北极星沿用 agent_tutor §13：未提示的新题原稿和模考里，重点技能的问题是否减少。

**要持续看的：**

| 指标 | 含义 |
|---|---|
| 同等帮助条件下，首次尝试做到的比例随时间的变化 | 学生是不是更独立了 |
| 隔 3 天以上、换一道题、不预告，再次做到的比例 | 有没有保持和迁移 |
| 有机会用到该技能的任务里，做到的比例 | 分母不含“没有机会”和“拿不准” |
| 段落里做到之后，整篇原稿里的核验结果 | 小练习的效果在整篇里是否保留 |
| 完成一个成果所需的时间、中途退出的比例、练习评价里的负面反馈 | 是否舒适 |

**不能当作学习证据的数字：**

| 数字 | 为什么 |
|---|---|
| 每周反馈次数 | 增加练习单位，它自然会涨 |
| 帮助后的通过率 | 给了提示，它自然会涨 |
| 表达出现率 | 表达显示在旁边，它自然会涨 |
| 求助次数 | 减少入口，它自然会降 |
| 学生与模型诊断的一致率 | 反复猜模型的答案，它自然会涨 |

**活动量护栏：** 每周整篇数和独立写出的英文词数。它们只说明练习量，不说明学会了什么。

3～5 人的试用只能发现机制问题，不能说明提分有效。

## 12. 需要 owner 决定的事

| # | 事项 | 现有决定或现状 | 本文的建议 |
|---|---|---|---|
| 1 | 每周整篇的数量 | 题库设计的试用护栏（[question_bank_first_practice.md](question_bank_first_practice.md) §10 的 Deep guardrail）：每周精练篇数不能下降 | “每周至少 1 篇整篇”作为待验证的安排，针对每周能练 2 小时以上的学生。原护栏是否修改，等首轮数据 |
| 2 | 修改后的全文分数 | 改写稿重新评分，进展页有“改写前后” | 最小修改只核验问题本身；“改全文”保留现状 |
| 3 | 练习分数的位置 | 反馈第一屏显示总分和四项分 | 移到第二屏。依据的研究对象是小学生，高分学生是例外，所以这是产品判断，不是研究结论 |
| 4 | 首次体验 | 注册后填 7 项问卷 | 先问 2 项，提供“贴一篇旧作文” |
| 5 | 段落和最小修改算不算每周次数 | 速刷通过和精练各算一次 | 都算一次；整篇另外单独显示 |
| 6 | 段落级的新题检验算不算迁移证据 | agent_tutor §9.2 只定义了原稿 | 可以触发重点退出的流程，但退出至少还需要一次整篇证据 |
| 7 | 范例学习 | 不给范文、整段、模板（G4） | “不代写当前作文”和“不给任何范例”是两件事。建议维持不给范文；对连续失败的学生，除了用他自己的一句话示范（§7.5），是否允许用一个与雅思题目无关的两句话例子说明“理由加解释”是什么样子，请决定 |
| 8 | 提交前自检 | owner 决定不加入（agent_tutor §17 第 5 项） | 本文遵守，无需再定 |

## 13. 顺序

| 顺序 | 内容 | 要回答的问题 |
|---|---|---|
| 先补基础 | 卡片与正文接续；反馈与修改接续；核验状态；帮助来源记录；论证目标的评测集 | 学习任务能不能连续完成，结果可不可信 |
| 首轮核心试验 | 一个论证目标；段落练习；标注；最小修改；新题检验；今天的清单 | 学生能不能更快完成有效修改，并在新材料上再次做到 |
| 第二轮 | 按证据选任务；按时间安排；按能力减少帮助；整篇检验 | 短训练能不能稳定服务整篇写作 |
| 后续扩展 | 搭桥；自己审题；受控的找错；用时观察 | 哪些附加训练确实改善了特定学生的问题 |

第二轮依赖分类表 v2 校准和帮助事件的技能归因（agent_tutor 第二阶段）。

提醒和触达渠道不在本文范围内，但复习和“今天”都依赖学生回来，需要另行设计。

## 14. 暂缓和没有采纳的

| 想法 | 处理 | 原因 |
|---|---|---|
| 表达出现后自动拉长复习间隔 | 暂缓 | 出现不等于掌握，会把误判写进学习计划 |
| 论证链四格（主张、解释、例子、回到题目） | 改为 §8.3 的标注 | 固定结构会让学生去迎合格式；有解释句不等于解释有效 |
| 学生预测与模型诊断比对，统计一致率 | 改为 §9.6 的自我反思 | 未校准的诊断不能当标准答案 |
| 重写后盲选哪一版更好 | 暂缓 | 同上 |
| 按离考试的日期关闭教练入口 | 改为 §9.7 | 日期不代表能力 |
| 只告诉错误数量，让学生自己找 | 暂缓 | 依赖诊断数得准 |
| 衔接练习 | 暂缓 | agent_tutor §9.4 把“限制连接词次数”判为写作偏好，等分类表 v2 明确衔接类问题的定义 |
| 整段重述对照 | 不采纳 | 违反 G4。单句示范是允许范围内的版本 |
| 反方陪练 | 不采纳 | 相反观点是教练首次引入的内容，违反 G1 |
| 连续打卡、排行榜 | 不采纳 | 题库设计已列为非目标 |
