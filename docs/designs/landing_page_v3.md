# auglearn 主页设计 v3

- **Created:** 2026-11-04｜**Status:** 备份。v3 是 auglearn 品牌页；project 0 宣传页改用 [v4](landing_page_v4.md)。
- **视觉稿：** [mockups/landing-v3.html](mockups/landing-v3.html)（单文件，约 300 KB，字体已内嵌）。默认英文，右上角可切换中文。也可以在地址后加 `?lang=zh` 直接打开中文版。
- **与前两版的关系：** 继承 [v2](landing_page_v2.md) 的宣传框架（前沿智能为核心，向外依次是个性化、记得住、普惠、写作）以及 v2 §6 的“不能说的话”。视觉、品牌和语言都按本文重做。v1、v2 的视觉稿保留作对照。

## 2. 设计方向

owner 对 v2 的反馈：灰色小字说明太多，不够简约大胆。v3 的做法：

1. **只在一处用力。** 首屏下方是一整条增强蓝的“增强舞台”：同一个想法分四步长成一句英文。这是全页唯一会自己动的地方，访问者也可以点击、用方向键切换或暂停。其余部分只用黑白两色。
2. **字体本身表明是谁写的。** 学习者写的字一律用 Newsreader（产品里作文用的衬线体）；老师和界面用 Geist。在舞台上，学生的话是衬线体，老师的追问是无衬线体，不需要额外标注。
3. **大字号、少字数。** 首屏标题最大 168px；每一节只有一个标题和一段正文。正文最小 17.5px，次要文字的颜色加深到 `#3F4249`，不再用浅灰小字。
4. **去掉模板感。** 不再用等宽小标签、全大写眉题、居中点分隔的元信息、按钮上的箭头、审阅标注，也不再用一排排相同的圆角卡片和逐节淡入的动画。只有真正有先后顺序的内容才编号（舞台四步、产品四步、路线图）。

### 色板

| 名称 | 值 | 用途 |
|---|---|---|
| White | `#FFFFFF` | 底色 |
| Black | `#000000` | 文字、主按钮、分隔线 |
| Augment | `#3340FF` | 舞台底色、字标里的 aug、宣言第二句、默认档位符号；与白字的对比度约为 6.3:1 |
| Tint | `#ECEEFF` | 提示性的浅底，例如“即将推出”和速刷用量条 |
| Surface | `#F3F4F6` | 语言切换、产品截图底板、路线图 |
| Text-2 | `#3F4249` | 唯一的次要文字颜色 |

### 字号（英文 / 中文）

| 层级 | 英文 | 中文 |
|---|---|---|
| 首屏标题 | 64–168px，字重 640，字距 -0.058em，行高 0.9 | 56–148px，字距 -0.03em，行高 1.02 |
| 章节标题 | 44–84px，字重 620，字距 -0.048em | 字距 -0.02em，行高 1.12 |
| 舞台句子 | 30–62px；学生用衬线体，老师用无衬线体 | 行高 1.3，最大宽度 17em |
| 正文 | 19–22px | 行高 1.6 |

所有标题都用 `text-wrap: balance`，段落用 `pretty`，以减少单字落行。中文标题需要时手动加换行。

## 4. 中英双语

| 项 | 规则 |
|---|---|
| 默认语言 | 英文。首次访问不按浏览器语言自动切换 |
| 切换位置 | 导航右侧、登录按钮左侧，是一个两段式切换（EN / 中文）。当前语言显示为黑底白字，并设置 `aria-pressed` |
| 记忆 | 记在 `localStorage`（`auglearn.lang`）；URL 里的 `?lang=zh` / `?lang=en` 优先 |
| 同步 | 切换时一起更新 `<html lang>`、页面标题和舞台文案。舞台第 4 步在两种语言下都是同一句英文作文，这正是产品要展示的结果 |
| 排版 | 中文单独设置字距和行高（见 §2），不沿用英文的负字距 |
| 正式实现 | 建议放在 `app/[lang]/` 路由下，文案放在字典文件中。视觉稿里用 `data-t` 加字典的写法只适用于演示 |

## 5. 可访问性与动效

- 舞台使用 `tablist` / `tab` 结构，支持左右方向键切换。鼠标悬停时暂停，也有明确的暂停按钮。
- 开启“减少动态效果”时，舞台不自动播放，句子切换没有过渡。
- 所有可聚焦元素都有 2px 的增强蓝焦点框。
- 移动端（375px）没有横向溢出。导航只保留字标、语言切换和登录；舞台的标签只显示数字。
