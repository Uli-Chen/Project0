## 1. 页面目标

| 项目 | 内容 |
|---|---|
| 读者 | 中国大陆成年雅思考生，目标 6.5～7，写作是短板；次要读者是潜在合作方与早期投资人 |
| 唯一转化动作 | **申请内测**（对应商业备忘录阶段 2「约 20 名邀请用户」）。现阶段默认暂停注册，所以按钮不叫“免费注册” |
| 次要动作 | 「看它怎么教」锚点到工作流；已有账户「登录」 |
| 一句话要让人记住 | 它不给范文，它把**你自己的想法**写成好的英文 |

## 2. 从 devin.ai 借什么

| devin.ai 的做法 | 我们的对应 |
|---|---|
| 近白底色 #F7F7F7、近黑文字、大量留白 | 底色 `#F6F6F3`（略暖，呼应产品的“纸面”），文字用产品现有 `--ink #1a1d23` |
| 左对齐的大标题 + 一行说明 + 黑色胶囊主按钮 / 白色描边次按钮 | 同样结构；中文标题 52–56px、字重 500、紧字距 |
| 产品界面截图放在**雾面天空**背景的圆角画框里 | 用 CSS 径向渐变做“晨雾蓝”画框，里面是真实流程的界面（不是插画） |
| 发丝线（1px 浅灰）分隔、网格竖线 | 每个分区之间一条发丝线；工作流区左右各一条竖线 |
| 卡片式能力墙（上图下文） | 「不是另一个批改工具」六宫格 |
| 编号 01–04 的左右交替工作流 | 写前 → 写中 → 评分反馈 → 改写对比 |
| 「Recently shipped」更新日志 | 「最近更新」，用真实提交日期，体现一人公司 + Agent 的迭代速度 |
| 「Enterprise security」勾选清单 | 「分数可信、数据归你」清单，只写代码里已经实现的 |
| 结尾大号居中 CTA + 极简页脚 | 「从下一篇开始，写你自己的观点」 |

**不借：** 顶部 logo 墙（我们没有用户，不编造）；营销数字（改为可溯源的研究数据，并标注来源）。

## 3. 宣传点（按重要性）

页面的全部文案由下面九点展开。每点给出依据，方便后续改文案时不越界。

| # | 宣传点 | 页面说法 | 依据 |
|---|---|---|---|
| 1 | **你的思路，不是范文** | 立场、理由、例子都来自你。教练不给范文、不套模板，每条建议都引用你的原话 | 00 总览 §1 原则「用户的思路优先」 |
| 2 | **先追问，再指方向，最后才示范** | 苏格拉底式引导：答对就收束，卡住就换方法 | 00 总览 §1「引导先于给答案」；agent_tutor §1 |
| 3 | **帮助会逐渐减少** | 记录每个问题给了多少帮助，同一技能下次从更少的帮助开始 | agent_tutor §1「帮助逐渐减少」 |
| 4 | **全程陪写** | 写前梳理提纲，写中选中句子就能问，写后回顾 | 原型 03、04、07 |
| 5 | **每篇只讲最重要的三个问题** | 定位到句子；默认只推进一个，改完再看下一个 | 商业备忘录 §4；agent_tutor §2 |
| 6 | **改写闭环** | 深化改写 → 再评分 → 两稿对比；“这篇改好了”“提示后做对了”“新题上独立做对了”分开记录 | 原型 08、09；agent_tutor §2 第 4 条；研究：多稿修改效果更好 |
| 7 | **记得你，而且有证据** | 每条记忆都能指到原句和日期；你可以查看、修改、删除 | agent_tutor §1「证据记忆」；00 总览「记忆透明」 |
| 8 | **分数和辅导分开** | 评分只看题目、冻结稿和评分规则，看不到记忆与辅导；练习分与模考分分开统计；标注“AI 实验性预估，非官方成绩” | 00 总览 §1、§3 底线 3；agent_tutor §4 |
| 9 | **没时间写整篇也能练** | 题库按主题推荐一道题并说明理由；速刷一张主题卡片，卡片只收你自己的原话，之后可以直接写成作文 | 原型 12、13 |

### 3.1 可以引用的外部数据

| 数据 | 用法 | 来源（需在页面脚注保留） |
|---|---|---|
| 大陆学术类雅思写作平均 5.7，阅读 6.2 | 「写作是最难提分的一项」 | British Council 2024–2025 数据，经媒体报道 |
| 自动写作评估元分析效应量 g ≈ 0.55–0.59，多稿修改、长期使用效果更好 | 支撑「改写闭环」 | Fleckenstein et al. 2023；Ngo et al. 2022 |

### 3.2 不能说的话

- 不承诺提分、不说“保过”“7 分”；
- 不说“和考官评分一致”——评分可信度是阶段 1 的待验证目标（±0.5 以内 ≥80%），未达标前只能说“目标”；
- 不放用户数、好评、客户 logo、媒体报道；
- 不说“数据不会用于模型训练”——隐私说明第 4 节这项仍【待定】；
- 不出现价格（商业模式未验证）。

## 5. 视觉规范

| 项 | 值 |
|---|---|
| 背景 | `#F6F6F3`；分区底线 `#E4E4DF`；卡片 `#FFFFFF`，边框 `#E7E7E2` |
| 文字 | 主 `#1A1D23`；次 `#5C616B`；弱 `#8A8F98` |
| 强调 | 墨蓝 `#2F56D6`（链接、追问气泡标记）；问题高亮琥珀 `#F4E3B5`；采用后的改动绿 `#DDEFE3` |
| 画框 | `radial-gradient` 叠加：`#C9D6E6`、`#E9EEF3`、`#B7C6D8`，加 2% 噪点；圆角 14px |
| 字体 | 界面 Geist + PingFang SC；作文正文 Newsreader（与产品一致）；编号与日期 Geist Mono |
| 字号 | H1 56/1.1 字重 500，字距 -0.02em；H2 40/1.15；正文 17/1.6；说明 15 |
| 按钮 | 高 44，圆角 999，主按钮黑底白字，次按钮白底 1px 边框 |
| 栅格 | 内容宽 1120，左右边距 32；分区上下 120 |
| 动效 | 沿用 `components/motion/tokens.ts`：进入淡入 + 4px 位移、180ms；画框内建议卡片 320ms 依次出现；尊重“减少动态效果” |

## 6. 响应式

主要读者经常在手机或微信内置浏览器打开（agent_tutor §2）。宣传页必须移动端优先验收，即使产品本体暂不适配手机：

- < 768px：导航收起为菜单；首屏标题 34px；画框只显示中间作文纸面 + 一张建议卡片；
- 能力墙变单列；工作流改为上图下文；对比表改为三张纵向卡片；
- 按钮全宽。

## 7. 实现建议

1. 路由放在 `app/(marketing)/page.tsx`，与 `(main)` 分开布局；未登录访问 `/` 时展示宣传页，已登录跳转到首页。需要先确认现有 `/` 的登录跳转逻辑。
2. 画框里的界面用静态组件重画，不引用业务组件，避免把业务数据或接口带进公开页面。
3. 「申请内测」先链接到一张问卷（外部表单或简单的 `/apply` 页），提交内容进入隐私说明的范围后再上线。
4. 正式对外前完成商业备忘录 §9 的合规确认（主体、托管、模型供应商）。
