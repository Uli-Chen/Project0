# project 0 用户工作流（现状）

- **写作时间：** 2026-11-14，对应 `redesign` 分支 `02b8131`。
- **用途：** 从学生的角度，把现在的产品“用起来是什么样”完整写一遍，作为升级工作流的起点。只写现状；最后一节是我观察到的断点，供讨论，不是方案。
- **默认配置：** 题库、速刷、独立模考都打开（`QUESTION_BANK_ENABLED`、`QUICK_ENABLED`、`CHECKPOINTS_ENABLED`）。题库关闭时的样子见 §8。

## 0. 一句话

学生每天打开“今天”，系统替他挑一道题；先用一张**速刷卡片**把想法理清，再把卡片写成一篇**精练**作文，拿到评分和问题，改写一遍，看两稿对比；被指出的句子和学到的表达进入**复习**；每隔两周做一次不靠教练的**独立模考**，用来看真实水平的变化。

```text
注册 → 设置目标 → 今天 ─┬─ 速刷卡片 ──(检查通过)──┐
                        │                          ▼
                        └─────────────────────→ 精练：写前提纲 → 写作 → 评估 → 反馈 → 改写 → 对比 → 完成
                                                                         │                    │
                                                         被指出的句子、采纳的表达 → 复习      本周进度、常见问题 → 进展
每两周：独立模考（40 分钟、没练过的题、不用教练）→ 进展里的成绩趋势
```

## 1. 第一次来

1. **注册**：名字、邮箱、密码（至少 10 个字符），确认后直接进入“设置目标”。注册可以由开关关闭，关闭时只能登录。
2. **设置目标**（全部必填，保存按钮会列出还缺什么）：
   - 目标分（5.0–9.0）；
   - 还有多久考试：知道日期就选日期，否则填准备周数（1–52）；
   - 目前水平（未考过 / 5 左右 / 6 左右 / 6.5 以上）；
   - 写作时最难的地方（可多选：没想法、想法说不清、英文表达不出来、语法错误多、写不完）；
   - 每周练几次、每次多长时间；
   - 想观点时更习惯先用中文还是直接用英文。
3. 这一步可以点“稍后”跳过，之后首页的“目标”一栏和作文页会一直提示去设置。

## 2. 每天打开：“今天”

学生看到日期、“本周已练 N / 目标次数”和一排进度点，下面是一块深色面板，系统只推荐**一件事**：

| 情况 | 面板上写什么 | 主按钮 |
|---|---|---|
| 有没写完的练习（任何主题） | 接着上次的速刷卡片 / 精练 / 模考，题目，状态、字数、用时 | 继续写卡片 / 继续写作 / 开始写作 |
| 这个主题还没练过 | 今天先用一张卡片把想法理清 | 开始速刷，约 10 分钟 |
| 这道题已有卡片 | 今天写这篇 | 用卡片写成作文 |
| 普通情况 | 今天写这篇 | 开始精练，约 N 分钟 |
| 主题里的题都精练过了 | 今天重写这道题 | 同题重写 |

- 推荐只在**上次练的主题**里挑题（第一次用就是第一个主题）：优先没见过的题，其次没完成精练的题，跳过正在进行的题，同等条件下挑练得最少的题型。
- **速刷只在“这个主题一次都没练过”时推荐**，之后默认推荐精练。
- 面板右侧三行：**先复习**（N 条到期，约几分钟）、**这次留意**（最近一次反馈里没被排除的问题）、**目标**（目标分和剩余时间）。
- 面板下方：独立模考的邀请（到时间才出现），然后是“全部主题”，每个主题显示完成进度、上次练习日期、观点卡片数量。
- 学生不想做推荐的题时，点“换一题”回到主题列表，进入某个主题后可以挑任意一道题点“速刷”或“精练”。题目页会标出“留作独立模考”的题，练了它就不再用于独立模考。

## 3. 速刷卡片（约 10 分钟）

目的：动笔之前，先用中文或英文把“题目问的每一点我怎么答、为什么”写清楚。

1. 页面中间是题目和一张卡片。卡片按题目拆成几个小问，每个小问有 2–4 栏（例如“好处 / 坏处 / 权衡结论 / 比较依据”），每栏最多 600 字，停笔一秒多自动保存。
2. 右侧是**教练面板**：
   - 卡片是空的时候，底部有示范问题“我没什么思路，帮我分析一下”“这道题该从哪里想起？”，也可以自己打字问。
   - 教练每次只回一个问题，不替学生写，也不替学生举例；学生回答后，回答气泡下有“放进卡片”，可以整段或选中一段放进某一栏。
   - 每张卡可以追问 2 次。
3. **检查**：点顶栏“检查”，教练逐个小问判断“已满足 / 还需展开”，并在没答完整的地方说明缺什么。每张卡可以检查 2 次，用完后 24 小时可以申请 1 次补充检查。
4. **通过**后，页面提示“题目问的都答到了”，主按钮变成“用这张卡写成作文”。卡片内容会自动填进精练的提纲。没通过也可以从“更多”里选“不检查，直接写成作文”。
5. 中途可以“先放一放”，回到首页时会出现在“接着上次”。

## 4. 精练：写一篇完整作文（约 40–60 分钟，加上改写）

### 4.1 写前（提纲）

- 题目和一张提纲在页面中间：立场、两个理由（各有要点 / 为什么 / 例子）、反方思考。从卡片来的会已经填好一部分，显示“想好了 x / 9”。
- 右侧教练开场问一个问题。示范问题：“我没什么思路，帮我分析一下”“我有个初步立场，帮我看看站不站得住”；提纲有内容后变成“帮我看看提纲哪里还单薄”“帮我给理由想一个例子”。学生说到的想法会被记进提纲，也可以点任意一格自己写。
- 想好了点“开始写作”。写前对话最多 40 轮。

### 4.2 写作

- 提纲退到左栏当参考，中间是编辑器。顶栏显示用时（超过 40 分钟变色提醒）、字数（不到 250 词时显示“N / 250 词”）、保存状态。
- 右侧教练可以“提问”或问“英文怎么说”（用中文写想表达的意思）；示范问题如“不知道怎么开头，给我一点方向”“下一段该写什么？”。
- 选中正文可以让教练“理清这段 / 润色这句 / 检查这段”或带着这段去提问。教练给出的修改建议可以“采用”（直接替换正文）、“插入到光标处”、忽略或撤销。
- “主动提醒”默认打开：新写完一段（至少 30 词）停笔 8 秒，教练可能主动提示一次。
- 写完点“提交评估”。不到 250 词会提醒但允许提交；少于 50 词、主要是题目原文或不是英文时不允许提交。提交后这一稿不能再改。

### 4.3 评估与反馈

- 评估分“评分与诊断”“整理反馈”两步，页面显示已等待的秒数；超过 90 秒会提示可以先离开，作文已保存。
- **反馈**：
  - 总分和四项分（任务回应、连贯与衔接、词汇、语法），标明“AI 实验性预估，非官方成绩”；
  - 按影响排序的几个问题，每个有“改写方向”，正文里对应句子用蓝色标出，重复出现的问题会标“上次也出现过”；
  - 每个问题都可以“和教练讨论”，教练给的提示最多 3 级；
  - 回顾：本次重点做到了没有、突破、采纳的教练建议占全文多少；提纲里哪些点写进了文章。
- 主按钮“开始改写”；也可以从“更多”选“不改写，完成”。

### 4.4 改写与对比

- 改写稿从原稿开始。还没改的问题句保持标记，改过就不再标；顶部列出每个问题“还剩几句”。原稿和改写稿可以来回切换。
- 提交改写稿后再评估一次，进入**对比**：两稿分数、每个问题“已解决 / 解决了一部分 / 还没解决”、修订痕迹、立场有没有变。学生可以给这次练习打分（有用吗、还是你的观点吗）。
- 点“完成”，弹出“本篇小结”（记忆里新增或变化的问题，下一步回到本题主题或首页）。

## 5. 独立模考（每两周一次）

- **什么时候出现**：完成第一篇精练之后，且距离上一次合格的独立模考至少 14 天。首页出现“独立模考 · 40 分钟”的邀请，旁边有“规则”说明，可以选“七天后提醒”。
- **开始前**会问“你在别处练过这道题吗？”，只有回答“没有”才开始；否则换一道。题目从学生没见过的题里挑，优先“留作独立模考”的题。
- **写作时**没有教练、没有提醒，40 分钟倒计时按服务器时间走，刷新、离开、暂放都不会暂停。
- **计入成绩趋势**的条件：按时提交、提交前没用过教练、开始时符合条件。不符合的仍然有反馈，但在进展页列为“其他模考”并说明原因。没有合适的题时可以改做普通模考。

## 6. 复习

- 侧栏“复习”带到期数量。内容全部来自学生自己的练习：
  - **表达库**：写作时用“英文怎么说”并采用了的表达（中文意思 → 采用的英文）；
  - **错句本**：反馈里被指出的句子（每个问题最多 2 句），配上学生自己的改法，没改的配改写方向；
  - **观点卡片**：速刷整理过的卡片，按主题归类，可以只看已通过检查的。
- **今日复习**一次最多 12 条：先自己写一遍（“这句话，英文怎么说？”或“改这一句”），再“对照”自己当时的答案，自评“记住了 / 改对了”或“还不稳，再来一次”。记住的按 1、3、7、14、30 天间隔回来，没记住的当场排到最后再来一次。

## 7. 看进展

- 目标分、距考试（或计划备考周数）、每周次数、本周完成情况。
- **成绩**：优先显示独立模考的成绩趋势；还没有模考时显示练习原稿成绩，并说明“练习有教练帮忙，分数只作参考”。可以看总分或四项分。
- **改写前后**：每篇原稿和改写稿的分数对比。
- **常见问题**：问题出现次数和最近日期。学生可以把某个问题移除（不再用于推荐重点），也可以撤销或恢复。下面是自评的难点和语言习惯，可以去修改。

## 8. 其他入口

- **作文**：全部练习的列表（类型、状态、AI 预估分、更新时间），可以筛选进行中 / 已完成。可以“粘贴题目”写自己的题，作为自由练习，不计入主题进度。
- **账户设置**：名字、目标与节奏、外观、修改密码、删除账户；开启新教练（`TUTOR_V2_ENABLED`）时还有讲解语言（默认英文）、写作思考语言、新练习是否开启段落提醒。
- **题库关闭时**：侧栏只有“新建作文”“作文”“进展”。新建作文时选“练习（有教练）”或“模考（40 分钟独立完成）”，题目来自推荐、几个固定话题或粘贴。还没评估过的学生会看到“入门测试”（一篇 40 分钟独立完成的模考）。

## 9. 一个学生的一周（示意）

> 周一晚上，小林打开“今天”。教育主题她还没练过，面板建议“先用一张卡片把想法理清”。她点开速刷，卡片是空的，就点了“我没什么思路，帮我分析一下”。教练问她能不能想象一个离家上大学的学生会先遇到什么难处。她答了两句，把其中一句放进“坏处”，自己补了“好处”和结论，检查一次就通过了。
>
> 周三，首页直接推荐“用卡片写成作文”。提纲已经有了一半，她和教练聊了两轮补上例子，开始写作。写到一半问了一句“经济独立”英文怎么说，采用了教练的说法。提交后拿到 6.0，主要问题是论证跳跃和主谓一致。她改写了被标出的句子，改写稿 6.5。
>
> 周五，侧栏“复习”有 3 条：一条是“经济独立”的说法，两条是被指出的句子。她用两分钟做完。
>
> 两周后，首页出现独立模考的邀请。她选了“没有在别处练过”，40 分钟写完，进展页上多了第一个不靠教练的成绩点。

## 10. 观察到的断点（供升级讨论）

以下是我按现状走一遍时注意到的地方，属于观察，不是结论：

1. **推荐只看“上次练的主题”**：学生除非自己去主题列表，否则会一直在一个主题里打转；面板上也看不出为什么是这道题。
2. **速刷只在一个主题的第一次出现**：之后系统默认精练，学生不知道还可以先做卡片；而卡片是精练提纲最好的起点。
3. **一篇精练的步骤很多**（写前、写作、评估、反馈、改写、再评估、对比、完成），中间有两次评估等待，单次时间容易超过“每次多长时间”里填的时长；首页的“约 N 分钟”只算了写作。
4. **跳过“设置目标”没有代价**：首页的目标、剩余时间、每周进度都依赖它，跳过后很多信息是空的。
5. **复习只来自两种来源**（采用的表达、被指出的句子）：速刷卡片里的观点、对比里“已解决”的问题都不进入复习；没用过“英文怎么说”的学生，表达库是空的。
6. **独立模考的门槛比较严格**（第一篇精练之后、两周一次、必须是没见过的题、不能用过教练），刚开始的两三周进展页只有练习分数，而练习分数带教练帮助、只能参考。
7. **每周目标只看完成次数**：一次速刷通过和一篇完整精练都算一次。
8. **没有任何提醒**（邮件、通知）：节奏完全靠学生自己打开。
9. **配置上的未决项**：`FOCUS_ENABLED` 在界面上没有找到作用；题库关闭时“复习”页仍可通过网址打开。
