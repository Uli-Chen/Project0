## 模板

```markdown
## YYYY-MM-DD（第 N 周）

- 本周变化：合并 MVP-xxx 子项…；AC-xxx 由 not_run 改为 …（报告链接）
- 演示：能运行的流程与限制

- 在制品与评审排队：in_progress n／2，待评审 PR n／3
- 已测数据：质量／成本／延迟（未测写“未测”）
- 决定：…（第 3 级变更附 ADR 编号）
- 下周 ready：MVP-xxx
```
