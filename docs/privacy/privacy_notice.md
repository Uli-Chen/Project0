project 0 是 Oadwook Lab 开发的雅思写作练习服务。本说明告诉你：我们保存你的哪些信息、为什么保存、发给了谁、保存多久，以及你可以怎样查看和删除它们。

## 1. 简要说明

- 你的作文、提纲和与教练的对话，只用来为你提供练习、反馈和学习记录，**不用于广告，不出售给任何人**。
- 为了生成教练回复和评分，必要的练习内容会发送给 AI 模型服务（目前是 DeepSeek）。你的邮箱、名字和密码**不会**发送给模型服务。
- 为了排查问题和改进教练质量，我们会保存每次 AI 调用的记录。其中调用内容的副本保存 **90 天**，到期自动删除。
- 你可以随时删除单篇练习，或者删除整个账户及其全部数据。

## 2. 我们保存哪些信息

| 类别 | 内容 |
|---|---|
| 账户 | 邮箱、显示名、密码的加密哈希（我们不保存密码原文） |
| 学习资料 | 目标分数、考试时间、每周练习节奏、写作思考语言、讲解语言、你自己填写的难点、你在记忆页停用的条目 |
| 练习内容 | 题目、提纲、草稿、提交稿、改写稿、与教练的对话、教练给出的建议以及你是否采用、评分与反馈、主题卡片、模考检查点 |
| 练习记录 | 每篇练习的开始、完成、最后编辑时间 |
| AI 调用记录 | 每次调用的时间、用途、所用模型、配置版本、耗时、用量（token 数）和结果 |
| AI 调用内容 | 实际发给模型的消息和模型返回的原始文字（见第 5 节） |
| 登录安全 | 登录会话令牌的哈希；登录失败次数（按账户标识的哈希计数） |
| 服务器日志 | 访问时间、IP 地址、请求的页面地址，用于安全和故障排查 |

我们**不**收集你的手机号、身份证件或支付信息，也不使用第三方统计或广告追踪工具。

## 3. 我们怎样使用这些信息

- 提供练习功能：保存草稿、生成教练回复、评分、对比改写前后的变化、推荐题目、生成学习记录。
- 让教练“记得你”：在你之后的练习中，引用你以前作文里的原句和日期，提醒反复出现的问题。你可以在记忆页查看、停用或恢复这些内容。
- 保护账户安全：限制登录尝试次数，识别异常请求。
- 排查问题、改进教练：查看 AI 调用记录和调用内容，找出回复出错、重复追问或越界代写的情况，并据此修改教练的规则。

## 4. 发送给 AI 模型服务的内容

使用教练、评分、改写对比、速刷追问与检查等功能时，服务器会把完成这次任务**必需**的内容发给模型服务：

- 题目、你的提纲、正文或选中的句子、相关的对话记录；
- 必要的学习偏好：目标分数、你填写的难点、讲解语言。

**不会发送：** 邮箱、显示名、密码、登录信息，以及与本次任务无关的其他练习。

目前使用的模型服务是 **DeepSeek（深度求索）** 的官方接口。模型服务按其自身的服务条款和隐私政策处理收到的内容【待定：核对 DeepSeek API 条款中关于数据保存期和是否用于训练的规定，并附链接】。以后更换模型服务时，我们会更新本说明。

AI 生成的回复可能出错。分数是 **AI 的实验性预估，不是官方成绩**。

## 5. AI 调用内容的保存

**保存什么：** 每次调用实际发给模型的消息（包括系统指令和你的练习内容）以及模型返回的原始文字。我们**不保存**模型的内部推理过程。

**为什么保存：** 只有对照原始输入和输出，才能查清某次回复为什么出错，以及修改规则后是否真的变好。

**保存多久：** 90 天后自动删除。删除对应的练习或账户时，相关内容立即一并删除。

**谁能看到：** 只有服务运营者在排查问题和改进教练时查看。调用内容不会展示给其他用户，不会出现在你的练习导出文件中，也不会通过任何页面返回给你或他人。

另外，每次调用的**记录**（时间、用途、模型、用量和结果，不含内容）会一直保存，直到你删除账户。删除单篇练习不会删除这些记录，但它们不包含你的文字。

## 6. 存储位置与安全措施

- 数据保存在我们租用的云服务器上，位于中国大陆境外（Google Cloud 台湾区域）。
- 网站只通过 HTTPS 访问。
- 密码使用随机盐和 scrypt 算法加密保存；登录 Cookie 设置为 HttpOnly，浏览器脚本无法读取。
- 每个账户只能读写自己的数据。
- 数据库和备份文件只有服务运营者可以访问。

## 7. 保存期限

| 信息 | 保存到什么时候 |
|---|---|
| 账户、学习资料、练习内容 | 直到你删除对应练习或删除账户 |
| AI 调用记录（不含内容） | 直到你删除账户 |
| AI 调用内容 | 90 天；或删除对应练习、账户时 |
| 登录会话 | 30 天；退出或修改密码时立即失效 |
| 登录失败计数 | 15 分钟后清除 |
| 服务器日志 | 按服务器默认设置定期轮换【待定：确认保留期】 |
| 数据库备份 | 【待定：备份保留期】。删除账户后，已存在的备份中仍会保留你的数据，直到这些备份按保留期被删除；我们不会用备份恢复你已经删除的数据 |

## 8. 你可以做什么

- **查看：** 在作文库、卡片页、记忆页和进展页查看你的练习和学习记录。
- **纠正记忆：** 在记忆页停用你认为不准确的条目，教练之后不会再引用它们。
- **修改设置：** 在用户中心修改学习目标、讲解语言和其他学习偏好，或关闭段落提醒。
- **删除单篇练习：** 删除后，练习内容和相关的 AI 调用内容一并删除。
- **删除账户：** 在用户中心输入当前密码和确认文字后，账户及全部练习、卡片、学习记录、AI 调用记录和调用内容会被删除。

## 9. Cookie 与浏览器存储

- 我们只使用一个登录 Cookie，用来保持你的登录状态。
- 浏览器本地存储只用于记住外观主题（亮色、深色或跟随系统），以及速刷页面的一个临时标记，不保存你的作文内容。
- 我们不使用广告 Cookie 或第三方统计工具。
