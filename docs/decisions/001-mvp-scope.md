# ADR-001：先交付免费首闭环

日期：2026-10-23。状态：当前采用，适用于 MVP-1。依据：用户要求围绕首篇作文到第一次改写完成拆分开发。

## 背景

冻结 v0.1 同时覆盖多考试、长期画像、规划和计费，范围超过首个可演示闭环。原免费 100 LT 不足以体验 200 LT 深度闭环。

## 决定

只做成年邀请用户的雅思 Task 2 Web 闭环，免费提供一篇初稿、最多 12 次成功的额外 Tutor 回复和一次整篇改写。保留基础成本账本，暂缓 LT/支付、长期画像、规划、多考试、OCR、小程序与 L4。反思从必填改为可选，避免将文字输入形式等同学习效果。

原稿到改写可以超过一次会话，不以 35 分钟日计划限制；先做提示 L1～L3。代码采用模块化后端和独立 Worker，不先拆微服务。

## 替代方案与代价

一次做完整原 MVP 会增加并行依赖，也难判断用户为何退出。收敛后不能验证长期推荐效果或真实支付意愿；试用结果不可外推为商业模式已验证。

## 重新评估

完成 MVP-018 试用报告后，依据退出点、提示需求、评分质量与成本决定下一阶段。12 次提示上限为可调参数，调整需同时更新规格和成本报告。
