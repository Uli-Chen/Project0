# ADR-003：评分和学习效果分开验证

日期：2026-10-23。状态：当前采用。

## 背景

原方案双评、校准和置信区间均为设计，缺少独立评测结果；同篇改写包含提示帮助，不能直接等同能力提升。

## 决定

沿用双评＋条件仲裁＋校准作为待验证实现路径，建立单评基线与组件对比。独立测试通过后才向真实邀请用户提供评分。区间覆盖率未验证时不展示区间，不把模型 confidence 当统计概率。

初稿和改写使用同一 pipeline 独立评分；模型版本变化时需成对重评才能比较。MVP 记录辅助程度，不更新长期 mastery。问题 removed/resolved 与“掌握”明确区分。

## 代价

需要授权专家样本、独立测试集和版本存储；真实用户试用可能被评分质量关口延后。演示只能使用明确标识的开发结果。

## 重新评估

若单评在独立数据上达到同等质量且成本更低，可简化管线并保留回归证据。验证长期能力与推荐效果时增加新题、无辅助、盲评设计。
