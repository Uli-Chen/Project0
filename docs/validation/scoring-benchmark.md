# 评分评测协议

状态：待执行。对应 SCOR-004／AC-008；执行 AG-EVAL，专家标注由签约评分专家完成，结论由创始人确认。下述数字为本阶段计划与门槛，无实测结果。

## 数据与划分

1. 沿用 Alpha 500 篇专家评分作文的目标；数据必须有来源和使用授权。每篇双人独立评分，分歧按标注协议仲裁；原始评分与仲裁都保留。
2. 规划按约 60%/20%/20% 划为拟合、开发、最终测试；按学生、题目和改写链组成不相交组再分配，比例可因分组偏移，须报告实际数量。
3. 若关联成分过大导致无法形成独立测试集，补充不同学生与新题数据；不能通过随机拆作文绕过。最终测试目标至少 100 篇，覆盖低/中/高水平及不同话题；每个预定义分数段至少 20 篇，不足则扩大测试集，不声称该分段达标。
4. 预定义分段暂为 ≤5.0、5.5～6.5、≥7.0；按专家共识分组。专家一致性与模型一致性分别报告，不能把内部共识称为官方成绩。
5. 拟合集用于校准，开发集用于 Prompt 和阈值选择；测试集在配置冻结后评一次，报告后不反复用其调参。区间拟合若需单独校准子集，只从拟合/开发数据中预留，测试集不参与。
6. Git 只存数据清单、授权状态、匿名 ID、划分规则和哈希。作文与评分员身份放受控位置，不把私有样本写进报告。

## 对比方案

固定相同输入与数据划分，分别评估：单评 A、双评平均、双评＋仲裁、完整校准管线。每种报告准确率、MAE、QWK、分段偏差、延迟、调用次数和成本。不能拿不同数据子集上的最好结果比较。

## 通过门槛

- 专家共识 ±0.5 命中率 ≥80%，MAE ≤0.4，QWK ≥0.75。
- 各预定义分段平均有符号误差绝对值 ≤0.25，报告样本数；样本不足记 inconclusive。
- 至少 30 篇按分段抽取的固定作文重复评分 5 次，各篇标准差 ≤0.25；同时报告最大波动和异常个例。
- 反馈抽检至少 100 条，问题成立且引用正确的联合准确率 ≥95%，报告双人分歧和最终裁决。
- 题目复制、空白、非英语、越界长度、提示注入和缺失维度各有固定异常用例；不返回伪分数，不泄露数据。

比例报告附二项区间，误差类指标附 bootstrap 区间；这些描述样本不确定性，不把点估计包装为已证明适用于所有用户。500 篇不是充分性的保证。

## 预测区间单独开关

原方案的“置信区间”需明确实际预测对象。MVP 若展示，命名为“本篇评分预测区间”，名义覆盖率暂定 90%；记录残差或其他方法和独立校准数据。

开启前要求独立测试总体实测覆盖率 ≥90%、平均宽度 ≤1.5 band，低/中/高分段覆盖率均 ≥80%，并报告区间不确定性。未达到、样本不足或方法未定时保持关闭，不影响仅展示已达标点预测的试用方案。区间门槛是本阶段产品约定，不代表行业标准。

## 结果与变更

每次记录 commit、pipeline、供应商实际版本、数据哈希、标注版本、运行命令和完整指标。仲裁率 15–25%、单次成本 ¥0.30 都只是原规划假设，以实测为准。

供应商、Prompt、校准器、特征或量表变化均触发相关回归；失败时不替换当前可用版本。初稿/改写版本不一致时按契约成对重评。
