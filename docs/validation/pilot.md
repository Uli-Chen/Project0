# 首闭环试用协议

状态：待执行。任务 MVP-018。约 20 名成年邀请用户、两周是形成体验证据的计划，不是学习效果统计保证。

## 开始条件

全部 P0 验收通过，评分真实数据评测达标，创始人已确认试用支持时段，AG-OPS 告警与删除操作说明可用（见 [团队与组织](../organization.md)）。参与者知晓实验性评分；服务同意不包含样本用于训练/校准的默认授权。

## 记录口径

| 指标 | 分子／分母或定义 |
|---|---|
| 首稿提交率 | 有合法首稿用户／已同意且开始练习用户 |
| 反馈查看率 | 查看完整反馈用户／完整反馈已就绪用户 |
| 改写率 | 提交有效首次改写用户／查看完整反馈用户 |
| 完成率 | 查看就绪对比用户／已同意且开始练习用户 |
| 首闭环用时 | 首次开始至首次查看对比；分别报告总历时与活跃用时 |
| 提示需求 | 使用 L1/L2/L3 的人数、成功额外回复数、触达上限人数 |
| 可靠性 | accepted 请求失败率、恢复成功率、反馈 partial 比例 |
| 成本 | 实际供应商调用总成本／已完成闭环数；另报未完成闭环成本，不隐藏退出者成本 |

内部账号、演示模型、重复浏览单列排除；中途退出仍计入对应漏斗分母。按版本分组，不混合多次改版后的数据。

## 访谈与观察

围绕“是否理解最重要的问题、是否知道怎么改、提示是否过多、是否误解分差、哪里卡住”做短访谈。记录用户原意但去除个人信息，不要求留下真实作文到公共仓库。

商业计划的改写率 ≥50% 作为探索目标保留；小样本须报告人数、区间和缺失数据，不以达到一个比例就宣布 PMF。严重错误、流程失败或用户误解按影响排序进入新任务。

## 学习效果边界

同题改写提分仅说明辅助条件下本次作品变化。后续如要验证能力提升，应预注册新题、无辅助、教师盲评、练习时间相近的对照设计，按预期效应与方差估计样本量，并考虑延迟测验；不把该研究混作本轮试用已完成的结论。

## 结束交付

生成一份带实际数据的报告：流程漏斗、反馈质量、分数理解、调用成本、延迟、失败恢复、未解决问题、下一阶段建议。新增 ADR 决定继续改善、扩大样本或暂缓扩展；没有报告之前不自动进入多考试和支付开发。
