# 验证报告：填写主题

- 日期／执行角色（AG-QA／AG-EVAL 及会话）／创始人确认：
- 任务／需求／验收编号：
- 验证类型：契约／功能／质量／试用
- 结论：passed／failed／inconclusive
- commit／pipeline／数据集哈希：
- 环境／供应商实际版本／参数：

## 方法与复现命令

## 实际结果

报告分母、样本量、排除项、失败项、成本未知项和不确定性。未测量写“未测”。

## 证据

日志、测试输出、截图或可访问的报告链接；不含作文正文、密钥或个人信息。

## 限制与后续动作

更新关联任务与验收状态；需改变规格时引用 ADR。
