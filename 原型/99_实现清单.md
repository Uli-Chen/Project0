# 99 实现清单

用于实现时逐项对齐。每一项对应环节文档中的一个小节；**只有对应的验收用例通过后才能打勾**。打勾时在行尾补上提交号或简短说明，例如 `✓ a1b2c3d`。

用法：
- 交给 agent 的单位是“一个环节”或“一组编号”，例如“实现 SC-01～SC-08”。
- agent 完成后，创始人按条目的验收用例检查，再打勾。
- 文档改了，对应条目取消勾选并重新验证。
- 每个里程碑结束时，逐条检查第 0 节的全局不变量。
