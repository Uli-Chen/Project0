# 02 领取任务与载入上下文（①）

**位置**：每次练习的起点。上游：[11_计划](11_计划.md) 产生的 `plan_tasks`，或用户选择自由练习。下游：练习模式进入 [03_写前梳理](03_写前梳理.md)；模考模式直接进入写作（[05](05_提交与检查.md)）。

**目标**：把“一项任务”变成一个会话，并为教练准备好这次需要的全部上下文与开场白。

## 1. 任务的来源

| 来源 | sessions.kind | mode | 说明 |
|---|---|---|---|
| 计划任务 focus_practice | task | practice | 带重点 |
| 计划任务 rewrite | task | practice | 带重点，原稿预填为旧作全文 |
| 计划任务 mock_checkpoint | task | mock | 无重点 |
| 自由练习 | free | practice | 无重点；用户自选题目或随机 |
| 自由模考 | free | mock | 无重点 |
| 入门测试 | assessment | mock | 见 [01](01_入门.md) |

## 2. 首页“下一项任务”

`GET /api/plan/next` 返回当前计划中按 (week, seq) 排序的第一个 `status=todo` 的任务；没有计划时返回 `{type: "assessment"}` 或 `null`。

卡片显示：任务类型、重点名称（分类表 name）、instruction、reason、题目话题。按钮：开始、换一题、跳过。

| 操作 | 接口 | 规则 |
|---|---|---|
| 换一题 | `POST /api/plan/tasks/{id}/swap-prompt` | 按 [11](11_计划.md) 第 5 节的选题规则重新选一题；每项任务最多换 3 次 |
| 跳过 | `POST /api/plan/tasks/{id}/skip` | status=skipped；不触发计划调整；下一项任务顺延 |

## 3. 创建会话

`POST /api/sessions`

请求：

```json
{ "task_id": "t_123" }                          // 计划任务
{ "free": { "mode": "practice", "prompt_id": "p_edu_02" } }  // 自由练习；prompt_id 省略时随机
```

处理顺序：

1. **结束遗留会话**：该用户若有 `stage ∈ {feedback, compared}` 且未结束的会话，先对其执行结束流程（[10](10_记忆整理.md)、[11](11_计划.md)），保证记忆不漏更新。若有 `prewriting / writing / revising` 的未完成会话，返回 `409 duplicate` 并附该会话 id，前端提示“继续上次的练习”或“放弃它”（放弃：`POST /api/sessions/{id}/abandon`，会话标记 finished、不更新记忆）。
2. 创建 `sessions`；计划任务的 `plan_tasks.status = in_progress`，写入 `session_id`。
3. 初始阶段：practice → `prewriting`；mock → `writing`。rewrite 类型直接进入 `writing`，原稿草稿预填为 `source_essay` 的全文。
4. 组装教练上下文（第 4 节），存入 `sessions` 的上下文快照（`coach_messages` 第一条 `role=coach, action=context`，`meta_json` 保存 CoachContext）。
5. 生成开场白（第 5 节），mock 模式跳过。

响应：`{ session, opening: string | null }`

## 4. CoachContext

```ts
type CoachContext = {
  task: null | {
    type: "focus_practice" | "rewrite";
    focus: { primary: Code; secondary?: Code };
    instruction: string;
    success: string;
    coach_hints: { prewrite: string[]; nudge: string[] };   // 来自分类表
    extra: string[];                                        // B 类附加指令
  };
  prompt: { id: string; text: string; question_type: string };
  memory_digest: Array<{ code: Code; summary: string; status: Status; quote: string; session_date: string }>;
  ideas: Array<{ summary: string; topic_tags: string[]; session_date: string }>;
  preferences: { language_pref: string; nudges_enabled: boolean };
  last_session: null | { date: string; prompt_topic: string; one_line: string };
};
```

组装规则（全部由代码完成）：

| 字段 | 取法 |
|---|---|
| memory_digest | T/L 类、未删除、status ∈ {recurring, observed_once, improving}；按 `rankFocus` 的同一优先级排序取前 5 条（[11](11_计划.md) 第 4 节）；`quote` 取最近一条证据的原句 |
| ideas | kind=idea、未删除，与题目 topic_tags 有交集；按最近使用排序取前 3 条 |
| last_session | 最近一个已结束的会话；`one_line` 取其 review 中的 `one_line` 字段（[07](07_反馈与回顾.md)） |

上下文快照在会话创建时固定，会话进行中不随记忆变化而改变。

## 5. 开场白

练习模式调用 `opening`（[90](90_共享规范.md) 第 6.3 节）。

- 输入：CoachContext。
- 输出 Schema：`{ message: string }`，≤80 字中文。
- 规则：
  - 有任务时，先说今天的重点和原因；有相关记忆时，引用一条并说明来源日期；
  - 没有记忆时不编造“上次”；
  - 结尾引出写前第一个问题，或在 rewrite 类型时说明“这次在原文上改”。
- 失败时使用代码模板：“今天的重点是{name}：{instruction}。我们先从题目开始。”

开场白作为 `coach_messages(stage=prewriting, role=coach, action=opening)` 保存。

## 6. 界面

- 首页任务卡片；“自由练习 / 自由模考”入口。
- 点击开始后显示加载（开场白生成，目标 5 秒内），然后进入写前页面或写作页面。
- 写前与写作页顶部固定显示本次重点与 instruction（mock 不显示）。

## 7. 边界情况

| 情况 | 处理 |
|---|---|
| 计划中没有 todo 任务 | 首页提示本周任务已完成，提供自由练习与“提前开始下周” |
| 任务指定的题目已被该用户做过（例如自由练习时做了） | 创建会话前按选题规则重新选题 |
| 开场白调用失败 | 使用代码模板，不阻塞 |
| 记忆为空（例如入门前的自由练习） | memory_digest、ideas 为空数组 |

## 8. 验收用例

| # | 操作 | 期望 |
|---|---|---|
| 1 | 开始一项 focus_practice | 会话 stage=prewriting；开场白提到重点名称与 reason 中的证据 |
| 2 | 开始 mock_checkpoint | stage=writing；无开场白；无教练面板 |
| 3 | 开始 rewrite | 原稿草稿为旧作全文；stage=writing |
| 4 | 有一个 feedback 阶段未结束的会话时开始新任务 | 旧会话先完成记忆与计划更新，再创建新会话 |
| 5 | 有一个 writing 阶段的会话时开始新任务 | 返回 409，前端提供“继续”或“放弃” |
| 6 | 换一题 3 次后再换 | 返回错误提示 |
| 7 | 检查 CoachContext | memory_digest ≤5 条且无 resolved；ideas 与题目话题有交集 |
