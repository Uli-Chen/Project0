# 05 提交与检查（④）

**位置**：写作或改写结束时。上游：草稿（[04](04_写中协助.md)，模考时为普通编辑器）。下游：不可修改的作文快照与一条 `evaluations` 记录，交给 [06_评分与诊断](06_评分与诊断.md)。

**目标**：拦下不能评估的输入，把合格的作文变成带句子编号的快照，并启动评估。

## 1. 接口

`POST /api/sessions/{id}/submit`

请求：`{ "essay_kind": "original" | "revision", "text": "...", "elapsed_sec": 2280 }`

前置条件：
- original：stage=writing；
- revision：stage=revising，且原稿评估 succeeded。

## 2. 处理顺序

1. 保存一次草稿（与请求中的 text 一致）。
2. `checkInput`（第 3 节）。不通过返回 `422 input_rejected`，`message` 为原因，阶段不变。
3. 同一 `(session_id, essay_kind)` 已存在 essays 时返回 `409 duplicate` 与已有的 evaluation_id（防止重复点击）。
4. 生成快照，在一个事务中写入：
   - `essays`：text、`word_count = countWords(text)`、`sentences_json = splitSentences(text)`、`paragraphs_json`（每段的起止偏移与句子 id 列表）、`duration_sec = elapsed_sec`、`ai_word_count`（[04](04_写中协助.md) 第 6 节；模考为 0）、submitted_at；
   - `evaluations(status=queued)`；
   - `sessions.stage` → evaluating（original）/ re_evaluating（revision）。
5. 返回 `{ essay_id, evaluation_id }`，并在进程内启动评估（[06](06_评分与诊断.md)）。

## 3. 输入检查 `checkInput(text, prompt, essayKind, originalText?)`

按顺序执行，第一个不通过的规则即返回：

| # | 规则 | 返回给用户的原因 |
|---|---|---|
| 1 | 去除空白后为空 | “作文是空的。” |
| 2 | 字符数 > 20,000 | “内容过长，请检查是否粘贴了多余内容。” |
| 3 | 拉丁字母占所有字母字符的比例 < 80% | “作文需要用英文写。中文想法可以在教练面板里先说。” |
| 4 | `countWords < 50` | “至少写 50 词才能评估。” |
| 5 | 作文与题目的词集合重合度（作文词中出现在题目里的比例）> 80% | “看起来主要是题目内容，请写出你的回答。” |
| 6 | revision：与原稿文本（规范化空白后）完全相同 | “改写稿和原稿一样，先做一些修改吧。” |

词数在 50～250 之间只在评估结果中提示，不拒绝。

## 4. 快照的使用规则

- 快照提交后不可修改；改写产生新的 `essays(essay_kind=revision)`。
- 后续所有引用都用 `essay_id + sentence id`；界面高亮使用 `sentences_json` 中的偏移。
- `splitSentences` 结果中，每句 `text` 必须等于 `text.slice(start, end)`；单元测试覆盖缩写、引号、省略号、数字中的小数点。

## 5. 界面

- 提交按钮旁显示词数与用时；点击后显示确认：“提交后不能再修改本稿。”
- 被拒绝时在编辑器上方显示原因，正文保留。
- 提交成功后跳转评估等待页（[06](06_评分与诊断.md) 第 6 节）。

## 6. 边界情况

| 情况 | 处理 |
|---|---|
| 提交请求超时，用户再次点击 | 第 3 步返回已有的 evaluation_id，前端直接跳转 |
| 用户在两个标签页同时提交 | 唯一约束保证只有一份；另一个返回 409 duplicate |
| 文本中有全角标点或中文引号 | 分句与词数照常处理；不视为非英文（只统计字母字符） |

## 7. 验收用例

| # | 输入 | 期望 |
|---|---|---|
| 1 | 空白 / 30 词 / 一段中文 / 复制题目 | 分别返回对应原因；不创建 essays，不调用模型 |
| 2 | 合格作文 | 创建 essays 与 evaluations；stage=evaluating |
| 3 | 连续点击两次提交 | 只有一份 essays；第二次返回同一 evaluation_id |
| 4 | 改写稿与原稿相同 | 返回原因 6 |
| 5 | 含 “e.g.”“U.S.”“3.5” 的句子 | 不在这些位置断句 |
| 6 | 检查 sentences_json | 每句 text 与偏移一致；段落编号正确 |
| 7 | 采用过建议的练习提交 | ai_word_count 按规则计算；模考为 0 |
